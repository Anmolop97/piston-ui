## ⚡ What is Piston UI?

**Piston UI** is an open-source, beautifully crafted component ecosystem engineered for modern web developers and designers who demand both stunning aesthetics and top-tier runtime performance.

Unlike traditional heavy component libraries, Piston UI provides copy-paste ready, modular React components built on top of Radix UI primitives and Tailwind CSS.

### 🌟 Key Features

- 📊 **Production Dashboards**: Complete layout solutions including Trading (Agndex), Analytics (Astrix), Healthcare (Medesk), Finance (Bionis), and Web3 applications.
- 🚀 **High-Converting Landing Templates**: Bento-grid layouts, glowing hero sections, conversion-focused pricing tables, and social proof sliders.
- ✨ **130+ Animated Components**: Physics-based micro-interactions, expandable wallets, dynamic dock bars, glow borders, interactive switches, and 3D magnetic cards.
- 🌊 **Fluid Lenis Physics**: Zero-lag momentum smooth scrolling across pages with nested scroll container preservation and touch safety.
- ⚡ **Zero-Lag Navigation**: Client-side optimized routing with immediate 0ms page transitions and adaptive video streaming.
- 🌗 **Adaptive Themes**: Seamless Dark & Light theme switching powered by Tailwind CSS tokens.

---

## 🛠️ Tech Stack

- **Framework**: React 19 + TypeScript
- **Styling**: Tailwind CSS v4 + Radix UI Primitives
- **Animations**: Motion (Framer Motion) + Lenis Momentum Scroll
- **Bundler**: Vite
- **Icons**: HugeIcons + Lucide React

## 🚀 Quickstart

Get the platform running locally in seconds:

```bash
# 1. Clone the repository
git clone https://github.com/Anmolop97/piston-ui.git

# 2. Navigate into the project directory
cd piston-ui

# 3. Install dependencies
bun install
# or
npm install

# 4. Start the local development server
npm run dev
```

Open [http://localhost:5173](http://localhost:5173) in your browser to view the catalog.

## 📁 Project Structure

```text
piston-ui/
├── public/                 # Static assets, favicon, icons, and manifests
├── src/
│   ├── assets/             # Vector icons and Piston UI mascot SVG
│   ├── components/
│   │   ├── landing/        # Hero, Bento, Features, Testimonials, Pricing
│   │   ├── layout/         # App Sidebar, Header, Navigation, Smooth Scroll
│   │   └── ui/             # Radix primitives (Button, Dialog, Sheet, etc.)
│   ├── contexts/           # Theme and layout state providers
│   ├── data/
│   │   ├── contents/       # 130+ Animated components and UI blocks
│   │   ├── dashboards.tsx  # Dashboard catalog metadata
│   │   └── templates.tsx   # Templates catalog metadata
│   ├── pages/              # App routes (Home, Dashboards, Templates, AI Landing)
│   └── main.tsx            # Application entry point
├── package.json
└── vite.config.ts
```
