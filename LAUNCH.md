## 🏷️ GitHub Release v1.0.0

**Release Tag**: `v1.0.0`  
**Release Title**: `Piston UI v1.0.0 - Production-Ready React & Tailwind Component Library`

### Release Description:
```markdown
# 🚀 Announcing Piston UI v1.0.0

We are thrilled to introduce the first official public release of **Piston UI** — the complete React & Tailwind CSS component platform engineered for high-velocity builders.

### 🌟 What's Included:
- **📊 12+ Full Production Dashboards**: Agndex Trading, Astrix Analytics, Medesk Healthcare, Bionis Finance, Portfolio, and Web3 dashboards.
- **🚀 High-Converting Landing Templates**: Bento-grid marketing designs, dynamic pricing grids, and social proof components.
- **✨ 130+ Animated Components**: Physics-driven UI blocks including expandable wallets, glowing borders, dynamic docks, and magnetic cards.
- **🌊 Lenis Smooth Momentum Scrolling**: Fluid 120 FPS page feel with full touch-safety and nested scroll container isolation.
- **⚡ Instant 0ms Navigation**: Sliced catalog loading and optimized bundle architecture.
- **🎨 Custom Mascot Identity**: Adorable 'P' mascot vector logo in signature lime green squircle.
- **🌗 Dark / Light Theme System**: Complete design token support for seamless mode switching.

### 📦 Quick Start:
```bash
git clone https://github.com/Anmolop97/piston-ui.git
cd piston-ui
bun install
npm run dev
```

**Full Changelog**: https://github.com/Anmolop97/piston-ui/commits/v1.0.0
```
