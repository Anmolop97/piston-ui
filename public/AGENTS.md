# Piston UI for Coding Agents

Piston UI is a free, modern catalog of React components, animated building blocks, dashboards, and landing page templates built for Tailwind CSS.

## Overview
- **Browsing**: Fast, instant navigation across dashboards, templates, and UI components.
- **CLI Compatibility**: Ready for integration with shadcn CLI workflows.
- **Physics**: Integrated with Lenis smooth momentum scrolling.
